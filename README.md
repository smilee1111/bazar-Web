# HaatKhoj

HaatKhoj is a local shop discovery and community platform.

It helps people find nearby businesses, explore shop details, view locations, and read or share reviews. It also supports seller onboarding and admin moderation workflows.

Important: HaatKhoj is **not** an e-commerce application. Users do not place orders, process payments, or manage carts here.

This repository contains:
- `haatkhoj-frontend`: Next.js web app for users, sellers, and admins
- `haatkhoj-backend`: Node.js/Express API for authentication, shops, reviews, notifications, and role-based management
